## Deployment (Coolify, Docker Compose build pack)
- Files: `Dockerfile` (php:8.3-apache, pdo_mysql/gd/zip/intl/bcmath/opcache, curl), `docker-compose.yaml` (**.yaml**, Coolify's default name; `.yml` gave "Docker Compose file not found"), `deploy/docker-entrypoint.sh` (waits for MySQL, `migrate --force`, caches config/routes/views), `.dockerignore`.
- Services: `app` (expose 80, volume `zplus-storage` → storage/app, healthcheck curl /up) and `db` (mysql:8.0, volume `zplus-mysql`, no domain, not published).
- Env in Coolify: `APP_KEY` (generated with `php artisan key:generate --show`; must never change), `APP_URL=https://zplus.epf-dashboard.online`; `SERVICE_PASSWORD_ZPLUSDB` / `SERVICE_PASSWORD_ZPLUSROOT` auto-generated by Coolify.
- Domain in Coolify → Domains → Add Domain: service **app**, https, `zplus.epf-dashboard.online`, **port 80**, no path. Don't add `www.zplus…` (no DNS → Let's Encrypt NXDOMAIN error, site showed self-signed cert).
- `bootstrap/app.php` trusts proxies (127.0.0.1, 10/8, 172.16/12, 192.168/16) so https URLs and secure cookies work behind Traefik.
- Admin created in Coolify → Terminal → **app** container: `ADMIN_EMAIL=… ADMIN_PASSWORD='…' php artisan db:seed --force` (seeder only creates, never updates). Password change: `php artisan tinker --execute="\App\Models\User::where('email','…')->first()->update(['password'=>'…']);"`
- Updates: Coolify **Redeploy** (or Auto Deploy). During redeploy (~1 min) the site briefly shows "Bad Gateway" then "no available server" – normal.
- Guides: docs/DEPLOY_COOLIFY.md (this setup), docs/DEPLOY_VPS.md (plain Ubuntu + nginx alternative, with `deploy/nginx-zplus.conf`, `deploy/update.sh`).
- Live DB started empty: owner to add agency bank details, import the GeM workbook, set EPF/ESIC switches, enable Coolify backups. If agencies/logos are missing on the fresh DB, run `KnownLetterheads::applyZplus/applySwachha` via tinker.

- Employees with linked Agency → Client → Post dropdowns; encrypted bank/Aadhaar numbers; documents

- Tax invoices (`TaxInvoiceBuilder`) combining a client's sub-bills; totals box shows wages, employer EPF/ESIC, service charge
- Agency blocks + light-blue client blocks on every list and the dashboard
- Salary payout (bank transfer) sheet per locked month (`SalaryPayoutSheet`, Attendance → locked month → "Salary payout sheet", Admin/Accounts only): employee EPF 12% (wages capped at ₹15,000) and ESIC 0.75% (rounded up), only for staff switched on
- EPF / ESIC switched on/off per employee by the user (switches on the Employees list and in the form's KYC tab; `PATCH employees/{id}/statutory`). Drives the salary deduction and the employer EPF 13% (wages capped ₹15,000) / ESIC 3.25% per person on sub-bills, tax invoices and bill screens; stored per bill line (`invoice_lines.epf/esic`). Daily-contract staff switched on by migration to keep old behaviour. `App\Support\Statutory` holds the rules.
- Letterheads: Z Plus classic (with footer); SWACHHA banner on sub-bill, covering letter, tax invoice, appointment letter (fits one page), attendance certificate, salary payout sheet
- Version display and release notes
- **Data Upload** (`/data-upload`, Admin only, `App\Services\MasterImport`): one Excel template per master (agencies → clients → contracts → projects → posts → employees), built live with PhpSpreadsheet (Instructions sheet, heading comments, hidden Lists sheet for dropdowns, text format for numbers with leading zeros). Upload → check (New/Update/No change/Error) → Save. Matching keys: agency code; agency+client code; contract no.; contract+project code; contract+project+designation; employee code (or name+mobile). Blank cell = keep; required cells only for new records except identifying ones. Secrets (account no., Aadhaar) never exported.

## Lessons
- Store month columns as `Y-m-d` (SQLite unique index broke with `Y-m-d 00:00:00`)
- Blade: keep `@can` inside slots; no stray text after `@endif`; avoid `@if(x) (text` on one line – a "(" right after a directive breaks compilation; use closures/variables instead
- dompdf can't read private storage: logos are embedded as data URIs
- Coolify: compose file must be `docker-compose.yaml`; set domain port 80; no `www` domain without DNS; use `expose` not `ports`; Coolify `SERVICE_PASSWORD_*` vars auto-generate secrets
- In this cloud sandbox, Docker builds can't reach Debian mirrors (proxy 403); test images by injecting the proxy CA only in a scratch Dockerfile. Don't `pkill -f` a pattern that matches the running shell command.
